## 🚀 Fitur Unggulan

Platform ini dirancang dengan berbagai fitur untuk memudahkan analisis dan investasi Anda:

- **📈 Prediksi Time-Series AI**  
  Menggunakan model AI canggih (Time-Series) yang menganalisis pola data historis secara komprehensif untuk memprakirakan tren harga emas hingga **7 hari ke depan** dengan tingkat akurasi yang tinggi.

- **🧠 Sistem Pendukung Keputusan (SPK)**  
  Memberikan rekomendasi **Beli, Tahan, atau Jual** secara otomatis. Sistem ini dibangun berdasarkan perhitungan algoritmik yang kompleks dengan mempertimbangkan indikator momentum pergerakan pasar jangka pendek maupun panjang.

- **🧮 Kalkulator Investasi Pintar**  
  Dilengkapi dengan alat simulasi interaktif yang memungkinkan Anda menghitung estimasi **margin keuntungan (profit/loss)**. Cukup masukkan modal awal Anda dan lihat proyeksi hasilnya berdasarkan target harga dari prediksi AI.

## 🛠️ Tech Stack

Aplikasi ini dibangun menggunakan arsitektur web modern yang menjamin performa tinggi, skalabilitas, dan pengalaman pengguna (*User Experience*) terbaik.

### Frontend
* **[Nuxt 4](https://nuxt.com/)** - *The Intuitive Vue Framework* untuk SSR dan arsitektur aplikasi yang tangguh.
* **[Vue 3](https://vuejs.org/)** - *Progressive JavaScript Framework* dengan *Composition API*.
* **[Tailwind CSS v4](https://tailwindcss.com/)** - *Utility-first CSS framework* untuk desain antarmuka yang responsif dan modern.

### Data Visualization & Utilities
* **[Chart.js](https://www.chartjs.org/)** & **[vue-chartjs](https://vue-chartjs.org/)** - Membangun grafik interaktif yang indah untuk visualisasi tren harga emas.
* **[Axios](https://axios-http.com/)** - Mengelola *request HTTP* dengan efisien untuk komunikasi API.
* **[Lucide Vue](https://lucide.dev/)** - Menyediakan ikon vektor yang ringan, *clean*, dan konsisten.

## 💻 Memulai (Setup)

Ikuti langkah-langkah berikut untuk menjalankan proyek ini di mesin lokal Anda. 

### Prasyarat
Pastikan Anda sudah menginstal perangkat lunak berikut:
- **[Node.js](https://nodejs.org/en/)** (Disarankan versi 18.x atau lebih baru)
- **NPM** (Umumnya sudah terpaket bersama Node.js) atau **PNPM** / **Yarn**.

### Langkah Instalasi

1. **Clone Repository**
   Buka terminal Anda dan jalankan perintah berikut untuk mengkloning repository ini:
   ```bash
   git clone <repository-url>
   cd goldInsight
   ```

2. **Instal Dependensi**
   Instal semua paket yang dibutuhkan aplikasi dengan menjalankan:
   ```bash
   npm install
   # Atau menggunakan pnpm/yarn:
   # pnpm install / yarn install
   ```

3. **Jalankan Server Pengembangan (Development)**
   Mulai server *development* dengan mode *Hot-Module Replacement* (HMR):
   ```bash
   npm run dev
   # Atau menggunakan pnpm/yarn:
   # pnpm dev / yarn dev
   ```
   > 🌐 Aplikasi sekarang berjalan dan dapat diakses di browser melalui: `http://localhost:3000`

4. **Build untuk Produksi (Production)**
   Jika Anda ingin mengompilasi aplikasi untuk lingkungan *production*:
   ```bash
   npm run build
   ```
   Untuk melihat pratinjau hasil *build* lokal, gunakan:
   ```bash
   npm run preview
   ```
